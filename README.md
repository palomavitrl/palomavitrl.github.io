# 🌐 Portfólio Web — Paloma Vitória

Interface web desenvolvida para apresentar minha trajetória, competências técnicas e projetos em **Engenharia de Software**, **Arquitetura de Sistemas** e **Ciência de Dados / IA**.

---

## 💻 Sobre o Projeto

Este projeto consiste em uma Single Page Application (SPA) / página estática com design moderno em tema escuro (blueprint/grid minimalista), responsiva e estruturada para oferecer uma navegação clara e direta sobre:

- **Sobre:** Apresentação acadêmica e áreas de foco (Arquitetura e Ciência de Dados).
- **Competências:** Organização visual de linguagens, frameworks, ferramentas e certificações.
- **Projetos em Destaque:** Showcase detalhado com links diretos para repositórios e arquiteturas implementadas.
- **Formação & Experiência:** Linha do tempo com histórico acadêmico, suporte técnico e trilhas de especialização.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3** (Estrutura semântica e estilização personalizada com padrão grid/cyberpunk minimalista)
- **JavaScript (ES6+)** (Interatividade e dinamismo de navegação)
- **Design & Layout:** Grid system responsivo, tipografia monoespaçada e componentes modulares
